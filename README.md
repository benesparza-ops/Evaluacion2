# Evaluacion2 - Software de Geolocalización y Gestión de API

## Descripción del Proyecto
Este repositorio contiene la solución desarrollada para la Evaluación N° 2 de Telepresencia y Entornos Innovadores de Colaboración Humana. Incluye la mejora del prototipo de geolocalización con Graphhopper API formateado en español y con precisión de 2 decimales.

## Instrucciones de Ejecución
1. Asegúrese de contar con Python 3 instalado.
2. Ejecute el script principal mediante el comando:
   python3 geolocalizacion.py
